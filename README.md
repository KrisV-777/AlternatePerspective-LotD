# Alternate Pespective + LotD Patch ([Nexus Mods Mirror](https://www.nexusmods.com/skyrimspecialedition/mods/58764?tab=posts))

A compatibility patch to allow alternate starting scenarios from [Legacy of the Dragonborn](https://www.nexusmods.com/skyrimspecialedition/mods/11802?tab=posts) (including its [Guild Hunter Start](https://www.nexusmods.com/skyrimspecialedition/mods/12253?tab=posts)) to 
work with [Alternate Perspective](https://www.nexusmods.com/skyrimspecialedition/mods/50307).
